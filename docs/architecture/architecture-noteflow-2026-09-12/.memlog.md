2026-09-12 | decision | Every mutation proposes optimistic concurrency, a client idempotency identity, and an account data epoch; stale conflicting writes are not silently accepted.
2026-09-12 | decision | Note drafts live only in an in-memory per-note session store; they are not an offline queue and carry no reload/close durability promise.
2026-09-12 | decision | Propose PostgreSQL full-text search using simple tokenization, explicit Vietnamese normalization, unaccent, and a GIN index; external search infrastructure is unnecessary for the approved scale.
2026-09-12 | decision | Backup import is a durable operation with pre-validation, an account-wide write fence, a single atomic replacement transaction, status reconciliation, and a new data epoch after success.
2026-09-12 | decision | Propose Vercel for the Next.js deploy and Supabase in the closest practical region; backup payloads bypass Vercel's 4.5 MB function payload limit through private object transfer.
