- **Sources:**

  [Addy Osmani – The Code Agent Orchestra](https://addyosmani.com/blog/code-agent-orchestra/) ·

- **Read:** 2026-10-24
- **Status:** idea

## Summary

- An "AI office" is a management layer over existing coding agents: roles, a
  task board, one worktree per agent, approval gates, triggers and budgets. It
  is not a new AI.
- Variants: parallel-run tools (Conductor, Claude Squad, Vibe Kanban), built-in
  CLI features (Claude Code agent teams), full offices (agent-office,
  Paperclip), and older frameworks (CrewAI, AutoGen, LangGraph, MetaGPT).
- Counter-evidence: a study of seven multi-agent systems found failure rates of
  41–86.7%, mostly from coordination design; one person can realistically
  review about three to five parallel agents; verification, not code, is now
  the expensive part.
- **agent-office** (very young, single author): headless `claude -p` turns with
  a `PreToolUse` guard that limits edits to the worktree and blocks `.git`,
  `.mcp.json`, Claude settings and secret files; no Bash, commands go through
  an allow-listed MCP tool without a shell; a worktree and reviewable diff per
  chat; background tools blocked in headless turns; a harness review that
  scores instruction quality from real outcomes (rejected diffs, failed
  commands, user corrections). Caveats: Windows needs WSL2; default admin
  credentials; the office can rebuild itself from agent-edited source.

## Compared with our architecture

- V4 Auto is already a small AI office in the recommended shape: one writer,
  several deterministic checks, a human approver.
- **Missing:** pre-execution guards for the worker (we only check after it
  finishes); a measure of instruction quality from real outcomes.

## Takeaways

1. A `PreToolUse`-style guard or allow-listed command tool is a concrete form
   of the AGY "floor" in [autonomy-levels](2026-11-07-autonomy-levels.md).
2. Their harness-review metrics (rejection rate, failed commands, user
   corrections) are a cheap way to evaluate AGENTS.md and skills.
3. Do not adopt a full office: the bottleneck would still be the owner.
