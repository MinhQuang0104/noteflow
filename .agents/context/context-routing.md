# V4 Lite context-routing context

Load context for the task's actual concern. L0 is root `AGENTS.md` and `.agents/routing/task-router.md`; L1 is the selected module; L2 is only the authoritative policy or evidence needed for a specific boundary.

Select one L1 module by default. Add a second only when its concern materially affects the same deliverable; state that reason. Never preload all modules or unrelated V3 workflow material. Follow references into L2 only as needed, and avoid copying detailed V3 rules into V4 guidance.

Keep the router deterministic and modules compact. Create or retain a module only when a recognizable recurring task class needs it, unrelated tasks can safely skip it, and reusable guidance justifies the load. Modules contain guidance and pointers, never runtime state or session facts.
